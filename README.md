# caldasciencia.co

Consulta en línea para actualizar el Plan de Acción de la Política Pública de Ciencia, Tecnología e Innovación de Caldas (Ordenanza 952 de 2023). Convenio CDTER – Gobierno de Caldas.

- `index.html` — la página (inicio, contexto, consulta en 7 pasos y resultados agregados).
- `config.js` — conexión con la base de datos (Google Apps Script) y enlace a la política de datos.
- `img/` — logos.
- `vercel.json` — caché (Vercel).

Publicación: Vercel despliega automáticamente cada cambio en `main`.
